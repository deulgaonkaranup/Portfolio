Geospatial Architecture

High-Throughput Geospatial Indexing with Protocol Buffers & Delta Encoding

Oct 2026 • 6 min read • Anup Deulgaonkar

Geospatial query endpoints often suffer from high payload serialization overhead when transferring dense point-in-polygon coordinates and POI metadata. During our architectural overhaul, we transitioned legacy serialization formats to Protocol Buffers coupled with delta encoding.

Key Optimizations

  • Delta Coordinate Compression: Storing relative offsets rather than absolute 64-bit floating point coordinates reduced byte representation significantly.
  • Geometry Quantization: Scaled floating-point coordinates into discrete integers for fixed precision, trimming mobile API payload sizes by ~50%.
  • Zero-Copy Deserialization: Streamlined payload parsing directly on the server to prevent CPU stalls under peak concurrency.
// Example Protocol Buffer definition for quantized geometry
syntax = "proto3";

message SpatialPoint {
  sint32 delta_x = 1; // Quantized integer offset
  sint32 delta_y = 2;
}

message GeospatialFeatureBatch {
  uint64 base_latitude = 1;
  uint64 base_longitude = 2;
  repeated SpatialPoint points = 3;
}

The resulting architecture yielded a 1.7x payload size reduction and increased request concurrency by roughly 40% under load tests.
